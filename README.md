# `px2cosmo`: Pixel to Cosmology 

A new neural population inference framework for constraining cosmology using high redshift galaxies from Hubble and JWST.

## installation 

```
git clone https://github.com/changhoonhahn/px2cosmo.git
cd px2cosmo
pip install -e . 
```

This package relies on [`zeus21`](https://github.com/ZeusCosmo/Zeus21): 
```
git clone https://github.com/julianbmunoz/zeus21.git zeus21
cd zeus21/
pip install .
```
